# Tenzin's Linux Personalizations

Customization stuff I like in linux environments. Saved here.

## `zsh` Setup

Install `zsh` if not on the machine (really should be on most standard boxes these days).

Run `zsh ./zsh_setup.sh` to install zsh extensions and add a line to `~/.zshrc` that sources this repo's `.zshrc` (an existing `~/.zshrc` is kept, not overwritten). Put machine-specific overrides in `~/.zshrc` after that line; edit shared config here in the repo.

Install `fzf` (on Mac `brew` is a good option).
